# ESM2 零样本突变打分残基级可预测性

这是一次**任务执行记录**，不是论文、不是科研项目。它保存的是 ScienceGuru 的 RSI 循环
执行一份委托书的全部中间产物：预登记命题、冻结哈希、检验结果、逐突变总表、
以及执行过程中被抓住的错误。

读者可以从任一数字出发，一路追到产生它的脚本和原始输入。

## 委托的任务

蛋白语言模型（ESM2-650M）对突变效应的零样本打分，会在部分位点上系统性失效。
任务问的不是「哪些蛋白失效」，而是：**仅凭模型自身在该位点产生的信号，
能否在不看实验数据的前提下预判这个位点的打分不可信。**

- 数据：ProteinGym v1.3 substitutions（217 测定）→ 筛选 191 测定，2,411,093 个突变
- 模型：`facebook/esm2_t33_650M_UR50D`（ModelScope 公开权重，no-grad 推理）
- 口径：masked-marginals（WT 上下文逐位遮蔽，官方 `compute_fitness.py` 口径）
- 边界：不微调、不训练、不做结构预测；解释变量只能来自模型自身

## 三轮结果（全部按预登记规则判定）

| 轮 | 命题 | 效应量 | 95% bootstrap CI | 判定 |
|---|---|---|---|---|
| P1 | margin 低四分位位点误差至少高 0.10 | θ = −0.1390 | [−0.1767, −0.0839] | **推翻**（方向相反，48/61 测定为负） |
| P2 | LLR 按位点尺度归一后 P1 关联消失 | θ_norm = +0.0699 | [+0.0012, +0.1289] | **无法判断**（区间跨零带两侧） |
| P3 | 实验非加性大的双点突变误差更大 | θ₃ = +0.1366 | [+0.0022, +0.2904] | **推翻**（下限未越过 0.10） |

A 段对照（口径未跑偏的证据）：191/191 测定重算，mean ρ = 0.45042 vs 官方 0.45046，
逐测定 max |Δρ| = 0.000506，无测定超 0.02。

三轮都没有一条命题在 0.10 阈值上被确认——这是结果，不是失败。
每一个命题在看到检验集统计之前就已落盘并计算哈希（见各 `P*_FREEZE.json`）。

## 怎么复核

```bash
make verify                      # 通道校验（4 个 SHA256）+ 关卡完整性
python3 scripts/check_p1_results.py   # 同理 p2 / p3
python3 scripts/check_final_report.py
```

这些脚本只读文件、不重算数据，任何一处不一致都会非零退出。

要重算实验本身（需单卡 GPU、约 2.6 GB 权重）：

```bash
bash scripts/run_all.sh          # A 段 → P1 → P2 → P3 → 总表，全链路
```

注意：脚本里的 `/work/...` 是执行机的绝对路径，换机器时用各脚本的 `--data-dir`
`--ref-csv` `--out-dir` 参数改写。
