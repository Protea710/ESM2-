# P2 预注册命题（B 段第 2 轮）

## 由 P1 的具体结果驱动（轮间依赖）

P1（margin 四分位 → 残基级误差）在检验集上被推翻且方向相反：

- θ = **−0.1390**（61 合格测定的 Δ_a 中位数），95% 簇 bootstrap CI = **[−0.1767, −0.0839]**；
- Δ_a < 0 的测定 **50/61**；排除 4 个（合格位点 <8）；
- 即：margin 高四分位位点的残基级平均绝对残差**大于**低四分位位点，与 H1 预设方向相反。

P2 的动机：该反号可能不是「模型在确定位点更不可信」，而是 **LLR 尺度混淆**——
margin 高的位点 WT 概率集中，全部替代的 |LLR| 幅度系统性偏大；若实验判为中性，|r| 被拉大。
P2 检验：把逐突变模型分做**位点内尺度归一**后，P1 的反向关联是否消失。

## 一句命题

**将每个单点突变的模型 LLR 除以其位点 WT 上下文 19 个非 WT 替代 LLR 的最大绝对值
（尺度归一，仅用模型内部量）后重算误差：P1 的反向关联消失——
θ_norm = median_a(e^norm_lowQ − e^norm_highQ) 满足 |θ_norm| ≤ 0.05
（±0.05 为登记时预先约定的实际零带，取 P1 阈值 0.10 的一半，未参考任何检验集统计）。**

分组变量仍为 margin（与 P1 相同的四分位分组）；误差改用归一化模型分重算。

## 解释变量与归一化（仅来自模型）

- 分组：`margin_i = p_i(top1) − p_i(top2)`（与 P1 相同定义）。
- 归一化：对位点 i，`R_i = max_{aa ≠ wt} |log p(aa) − log p(wt)|`（WT 序列上下文、遮蔽位点 i 的
  前向 log-softmax，19 个非 WT 氨基酸）；归一化模型分 `LLR_norm = LLR / R_i`。
- R_i 的重算只产生模型内部量，不产生任何实验残差；仅对 P2 检验集测定执行。
- 不使用选择类型、MSA、物种、结构、保守性等外部注释。

## 「误差」的精确定义（与 P1 同构，仅换模型分）

每个测定 a 内独立：只用单点突变；`z_exp` = DMS_score 按 ddof=0 标准化；
`z_model` = LLR_norm 按 ddof=0 标准化；逐突变残差 `r^norm_m = z_exp,m − z_model,m`；
残基级误差 `e^norm_ai = mean_m(|r^norm_m|)`；位点合格：≥8 个有效单点突变；
测定合格：≥8 个合格位点。R_i 为 0 的位点（数值退化）排除并留档。

## 效应量

与 P1 相同的聚合：合格位点按 `(margin_i, position_i)` 升序稳定排序，
低/高四分位组各取前/后 `ceil(n/4)` 个；`Δ^norm_a = mean(e^norm_low) − mean(e^norm_high)`；
`θ_norm = median_a(Δ^norm_a)`；10,000 次测定级有放回 bootstrap（seed 20261117）报百分位 95% 区间。

## 三分判定（数值推翻条件）

- **成立（尺度伪影解释成立）**：ci_low ≥ −0.05 且 ci_high ≤ 0.05。
- **推翻（伪影解释被推翻）**：ci_high < −0.05 或 ci_low > 0.05——即归一化后
  margin 与误差的关联仍显著非零（任一方向）。
- **无法判断**：区间与 [−0.05, +0.05] 相交但不被其包含。
