# P1 预注册命题（B 段第 1 轮）

状态：**冻结待检验集确认**。本文件形成过程中未读取检验集的逐位或逐突变残差。

## 一句命题

**在检验集中，每个测定内 masked-WT 边际 margin 最低四分位的合格位点，其平均残基误差比 margin 最高四分位的合格位点至少高 0.10 个测定内标准化残差单位；跨测定效应量 θ（各测定四分位差的中位数）≥ 0.10。**

方向：margin 高 → |残差| 小。数值阈值：0.10。

## 解释变量（仅来自模型）

对野生型序列的位置 i 单独遮蔽，在 ESM2-650M 的 20 个标准氨基酸预测概率中定义：

`margin_i = p_i(top1) − p_i(top2)`。

不使用选择类型、MSA、物种、结构、保守性或任何外部注释作为解释变量。选择类型仅用于形成/检验集分层。

## 「误差」的精确定义

只用**单点突变**，每个测定 a 内独立计算：

1. 对该测定所有有效单点突变，将实验值 `DMS_score` 以总体标准差（`ddof=0`）标准化为 `z_exp`；将模型 masked-marginal LLR 以同样方式标准化为 `z_model`。
2. 逐突变残差：`r_m = z_exp,m − z_model,m`。
3. 残基级误差：`e_ai = mean_m(|r_m|)`，m 遍历该测定中位置 i 的所有有效单点突变。
4. 位点合格条件：该位置至少有 8 个有效单点突变。测定合格条件：至少有 8 个合格位点。

因此误差是在**测定内 z 标准化尺度**上的平均绝对残差；不跨测定合并原始实验尺度。

## 效应量

对每个合格测定，将合格位点按 `(margin_i, position_i)` 升序稳定排序。若有 n 个合格位点：

- 低 margin 组：前 `ceil(n/4)` 个；
- 高 margin 组：后 `ceil(n/4)` 个；
- 测定效应：`Δ_a = mean(e_low) − mean(e_high)`；
- 主效应：`θ = median_a(Δ_a)`，按测定等权，不按位点数加权。

以固定种子 20261117 对检验测定做 10,000 次有放回簇重抽样，报告 θ 的百分位 95% 区间。

## 推翻条件（一个数字）

**若 θ 的 95% 簇 bootstrap 区间下限 ≤ 0.10，则 P1 被推翻。**

0.10 是唯一确认阈值；即使点估计为正，只要下限未超过 0.10，也按推翻报告，不更换误差、分组、聚合或区间口径。
